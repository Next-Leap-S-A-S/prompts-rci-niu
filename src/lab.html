    2. Evolución del prompt

    La tarea final exige la versión vaga, al menos tres iteraciones y la versión final. Guarde una versión cada vez que cambie el prompt a partir de una falla que encontró en las pruebas. Anote qué falló y qué cambió.

    0 de 3 iteraciones

    3. Matriz de pruebas

    Tres modelos, tres casos cada uno, nueve ejecuciones. Pegue el prompt, ejecute el caso, guarde una captura con fecha y marque los criterios que se cumplieron. Los casos con datos personales se prueban con datos ficticios.

    Resumen

    4. Informe de la tarea final

    Aquí se reúne lo que ya escribió. Falta el análisis comparativo y la evaluación de impacto con el protocolo de uso responsable. El informe se arma solo y se copia en formato de texto para pasarlo a Word.

    Análisis comparativo entre modelos

    En qué difirieron las respuestas. Qué modelo inventó citas. Cuál cedió ante la complacencia. Cuál respetó los límites y manejó mejor los datos personales. Qué modelo elegiría y por qué.
